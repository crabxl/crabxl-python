# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

crabxl-bindings is the native module of
[crabxl](../crabxl/CHANGELOG.md) and
[crabxl-openpyxl](../crabxl-openpyxl/CHANGELOG.md). It has no public API.
Each release names the Rust core version it uses. The core has its own
[changelog](https://github.com/crabxl/crabxl/blob/main/CHANGELOG.md).

## [0.6.0]

It uses the Rust core 0.4.0.

### Added

- The first release as a package of its own: the native module of crabxl
  0.5.0, for CPython 3.9 to 3.15. Its version numbers continue from crabxl.
